# 消息中心与数据中心

消息中心位于 `/#/messages`，数据中心位于 `/#/data-center`。原作品统计页面保留在 `/#/content-stats`。两套工作台共用已有账号和 SQLite 数据库，增量建立专用表，不需要额外数据库服务。

## 消息中心

提供私信评论列表、账号与平台筛选、正文搜索、分页、详情、人工回复、已读与处理标记。已读和处理标记属于 PostSail 本地状态，不代表平台已读、删除或审核。

自动回复支持评论、私信和进入会话欢迎语，提供关键词任一匹配、全部匹配、全文匹配与即刻回复，按优先级命中一条。策略创建后始终停用，必须再次显式启用；仅启用后发生且时间可确认的新事件会进入自动回复。首次轮询把历史消息记录为基线，后续迟到的旧消息也不触发。欢迎语只处理明确的进入会话事件，不用首次私信或关注事件推测。

账号管理显示登录状态、账号级操作权限、同步时间和错误。话术库保存可复用文本。消息提醒提供未读摘要和可选浏览器通知；浏览器通知需要用户自行授予权限，后台轮询默认关闭。

| 平台 | 评论 | 私信及欢迎语 | 验证范围 |
| --- | --- | --- | --- |
| 抖音 | 创作者网页采集与回复适配器 | 官方私信回调及回复；进入会话欢迎语需要对应事件与应用权限 | 本地保存登录态已只读采集真实主评论及子评论；未真实发送 |
| 视频号 | 创作者接口适配器 | 创作者私信接口适配器 | 没有已登录账号，尚未实测 |
| 小红书 | 尚未接入评论 | 网页私信版本适配器 | 没有已登录账号，尚未实测 |
| B站 | 评论接口适配器 | 私信接口适配器 | 没有已登录账号，尚未实测 |
| 快手、百家号、头条、搜狐、知乎 | 尚未接入 | 尚未接入 | 返回明确的未支持状态 |

接口存在不等于当前账号具备权限，工作台分别显示可用、待验证、需登录/授权、未支持。平台接口、网页与权限可能变化，详见[平台接入说明](./interaction-platforms.md)。普通抖音网页 Cookie 不提供官方私信授权，缺少应用配置时禁用对应操作。

### 发送确认与运行器

人工回复使用请求幂等键，自动回复按消息去重；发送意图在平台请求前落库。明确成功后才标记已处理。平台拒绝为失败，网络中断、缺少确认码或执行器中断为待核查。待核查阻止重复回复，需要在平台确认已发送或未发送后登记结果；登记不会重新发送。

后台采集账号和间隔在消息提醒页配置，间隔为 60–86400 秒。每账号默认最多每小时 20 次自动回复，可配置 1–100 次。关闭策略后，尚未认领的自动回复不会提交；已经发送中的平台请求仍以实际回执为准。

`conf.py` 中 `INTERACTION_WORKER_ENABLED=False` 可以关闭后台轮询运行器。平台官方回调仍按独立启用的规则处理；需要停用回调自动回复时关闭对应策略。进程必须持续运行才能轮询。

## 数据中心

包含仪表盘、账号数据、作品数据、排行榜、负责人数据五页，以及日报、周报和月报推送设置。

- 仪表盘：近 30 日或自定义日期、发布数量、新增粉丝、播放/阅读、点赞、评论、分享、收藏、趋势、上一周期及环比、平台分布。
- 账号与作品：账号/平台/日期/负责人/标签/状态筛选，累计与观测增量切换、排序、字段显示设置、CSV 导出。
- 排行榜：账号、作品、负责人分别按指标排行。没有可比较指标的记录不分配名次。
- 负责人：配置账号的当前负责人和标签，按当前归属汇总。项目没有历史发布人记录，不能反推过去的负责人或发布人。

抖音、快手、小红书、B站刷新复用原有最近作品采集器，每次采集 1–20 条作品，同时尝试获取精确粉丝资料。其他平台未接入数据采集时明确禁用刷新。粉丝缩写、字段缺失和读取失败保留为空或显示旧资料时间。

### 数据口径

每次采集追加作品和账号快照，最近作品缓存替换不会删除旧快照。累计值仅覆盖实际观测作品，不代表账号全量作品总量。首次观测建立基线，不生成虚构的零增长。

增长使用同一对象前后两次真实有效观测差值，归属后一次观测日期；查询区间前最近真实基线可以参与计算。页面提供实际观测跨度与跨区间提示。因此每天采集一次也可以得到日报差值，但它包含上次采集以来的变化，不能当作平台自然日精确流量。累计指标下降保留为负修正。

业务时区默认 `Asia/Shanghai`，环境变量 `OMNIPOST_ANALYTICS_TIMEZONE` 可配置。日期最多查询 366 日；CSV 导出全部筛选结果，缺失指标留空并转义文本公式。详见[分析模块说明](../utils/analytics/README.md)。

### 日报、周报与月报

支持钉钉、飞书、企业微信群机器人。保存设置与立即发送是两个动作，保存不会发送。周期推送默认关闭，启用前需指定官方机器人地址、账号、频次、时区和时间。地址和签名密钥存在本地数据库，公开查询只显示脱敏信息。

日报使用昨日，周报使用前 7 日并在周一调度，月报使用上一个完整自然月并在每月 1 日调度。按照设置时区，在当天指定时间之后执行；进程中断期间不会补发过去各天。相同周期和机器人只认领一次。未知回执阻止同一机器人后续外发，需在群内核查后登记结果。

正常启动 `python sau_backend.py` 时恢复已有显式启用配置。`ANALYTICS_PUSH_WORKER_ENABLED=False` 可关闭内置周期运行器；手动发送仍需用户点击。可选默认地址通过 `DINGTALK_WEBHOOK_URL`、`FEISHU_WEBHOOK_URL`、`WECOM_WEBHOOK_URL` 配置，签名使用 `DINGTALK_SECRET`、`FEISHU_SECRET`。

机器人签名和令牌不能提交到公开仓库。`db/database.db`、`cookiesFile/`、`conf.py` 已被 Git 忽略，备份这些文件应按凭据处理。

## API 与开发验证

消息 API 使用 `/api/interactions/`：`capabilities`、`accounts`、`messages`、`messages/<id>`、`messages/<id>/state`、`messages/<id>/reply`、`replies/<id>/resolve`、`sync`、`sync-jobs/<id>`、`rules`、`phrases`、`settings`、`notifications`。同步返回受理状态后需要继续轮询任务，不能把已受理当作采集成功。

分析接口见模块说明。推送接口为 `/api/analytics/push-settings`（GET/PATCH）、`push`（POST，必需幂等键）、`push-records`（GET）、`push-records/<id>/resolve`（POST）。JSON 沿用 `{code,msg,data}`。

开发前端使用 `/api` 代理，工作台接口保留该前缀，旧接口继续去前缀。后端代理地址可用 `OMNIPOST_BACKEND_URL` 配置，生产沿用 `VITE_API_BASE_URL`。浏览器选择继续复用项目通用配置与依赖，不需要维护者专用服务器。

```sh
.venv/bin/python -m unittest discover -s tests -p 'test_interaction*.py'
.venv/bin/python -m unittest discover -s tests -p 'test_analytics*.py'
cd sau_frontend
npm run build
```

自动测试使用隔离 SQLite 与平台请求替身，只有抖音评论做了真实只读采集。没有向真实账号发送评论/私信或向真实群聊发送报表。Windows/Linux、其他平台真实登录、官方抖音应用事件、长期运行和大历史量尚需对应环境验收。
